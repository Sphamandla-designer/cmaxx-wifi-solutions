# Kiy Trucking Logo Pack

Vector and raster exports of the Kiy Trucking logo, rebuilt as clean, sharp
artwork from the supplied reference. The design is unchanged.

Brand colours: red #C0121E, white #FFFFFF, black #0B0B0B.

## Colour states

| File name | KIY | TRUCKING + swoosh | Background | Use on |
|---|---|---|---|---|
| kiy-trucking-full-colour | white | red | transparent | dark backgrounds |
| kiy-trucking-full-colour-on-black | white | red | black | anywhere, self-contained |
| kiy-trucking-full-colour-dark | black | red | transparent | light backgrounds |
| kiy-trucking-mono-white | white | white | transparent | dark photos, one-colour print |
| kiy-trucking-mono-black | black | black | transparent | light backgrounds, stamps, engraving |
| kiy-trucking-mono-red | red | red | transparent | one-colour red print |

## Textured versions

Every state also comes as kiy-trucking-textured-<state>, where KIY and TRUCKING carry the
distressed grunge texture from the original logo. The texture is real vector
artwork (no filters or raster effects), so it prints cleanly at any size.
Use the clean versions for small sizes, embroidery and engraving; use the
textured versions for large print, vehicle wraps and social media.

## Folders

- svg/  Editable vector files. Scale to any size with no loss. Each file has
        a "kiy" group and a "trucking" group so the colours can be changed.
- png/  Each state, clean and textured, at 1000, 2000 and 4000 px wide. Transparent background,
        except the on-black version which is solid black.

Use the SVGs for print, signage, vehicle wraps and embroidery digitising.
Use the 4000 px PNGs for large-format digital work, 2000 px for social media
and presentations, and 1000 px for web and email.
