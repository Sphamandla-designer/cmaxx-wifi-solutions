# Kiy Trucking logo

Vector and raster exports traced from the original logo supplied in
`WhatsApp Image 2026-10-24 at 14.55.22.jpeg`. The design is unchanged.

Colours: red `#C0121E`, white `#FFFFFF`, black `#0B0B0B`.

## Colour states

| File stem | KIY | TRUCKING + swoosh | Background | Use on |
|---|---|---|---|---|
| `kiy-trucking-full-colour` | white | red | transparent | dark backgrounds |
| `kiy-trucking-full-colour-on-black` | white | red | black | anywhere, self-contained |
| `kiy-trucking-full-colour-dark` | black | red | transparent | light backgrounds |
| `kiy-trucking-mono-white` | white | white | transparent | dark photos, single-colour print |
| `kiy-trucking-mono-black` | black | black | transparent | light backgrounds, stamps, engraving |
| `kiy-trucking-mono-red` | red | red | transparent | single-colour red print |

`svg/` holds the editable vectors (each has a `#kiy` and a `#trucking` group).
`png/` holds each state at 1000, 2000 and 4000 px wide, transparent except the on-black version.
